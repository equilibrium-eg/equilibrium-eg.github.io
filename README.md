# الاتزان الكيميائي — Chemical Equilibrium

Adaptive learning platform for Egyptian 3rd-secondary chemistry (chemical equilibrium): diagnostic pre-test, three learning paths, six units with simulations, the **Acquire** assistant, post-test report, and Google Sheets logging.

- `index.html` — the built site (served by GitHub Pages).
- `src/` — editable sources: `content.js` (lessons, questions), `hints.js` (Acquire hints & explainers), `sims.js`, `app.js` (`CONFIG` at the top), `style.css`.
- `build.py` — rebuilds `index.html` from `src/`.
- `Code.gs` — Google Apps Script backend (paste into the Sheet's Apps Script and deploy as a Web app).
